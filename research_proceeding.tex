\begin{abstract}
We describe an open-source data-analysis pipeline for volatile organic compound (VOC) signals acquired by PTR-MS instrumentation. The pipeline formalizes run-aware segmentation, robust aggregation, blank subtraction, and multivariate exploratory analysis. The objective is reproducible extraction of treatment-level differences from high-frequency time-series measurements.
\end{abstract}

\section{Problem Statement}
Let $\mathcal{T}=\{\mathrm{H0},\mathrm{H1},\mathrm{Blank}\}$ denote experimental groups and let each run $r\in\mathcal{R}$ produce a set of room-level files $x_{t,r,j}(\tau,m)$, where $\tau$ is acquisition time and $m$ is mass channel (e.g., $m/z$ proxy). We seek robust group-level summaries $S_t(m,k)$ over block index $k$, while controlling transients and anomalies.

\section{Formalization}
For each file, define temporal blocks $B_k$ via gap-based segmentation. For each block and mass channel, we compute a trimmed robust statistic:
\[
\tilde{x}_{t,r,j,k}(m)=\mathrm{median}\left(\mathrm{trim}_{\alpha}(x_{t,r,j}(\tau,m),\tau\in B_k)\right),
\]
with $\alpha\in(0,0.5)$ (default $0.2$). Replicate aggregation is
\[
S_t(m,k)=\mathrm{Agg}\left(\tilde{x}_{t,r,j,k}(m): j\in\mathcal{J}_{t,r}\right),
\]
where $\mathrm{Agg}$ is median/mean with uncertainty interval. Blank-corrected signal is
\[
Y_t(m,k)=S_t(m,k)-S_{\mathrm{Blank}}(m,k).
\]
Pairwise treatment contrasts can be summarized by effect metrics
\[
\Delta_{a,b}(m)=\mathrm{Metric}(Y_a(m,\cdot),Y_b(m,\cdot)).
\]
For structure discovery, PCA is applied to matrix $\mathbf{Y}\in\mathbb{R}^{n\times p}$ after scaling/imputation.

\section{Research Contribution}
The pipeline unifies practical preprocessing constraints (run schedules, acclimation windows, transition exclusion) with robust statistics and interpretable multivariate analysis. It is suitable for reproducible exploratory research and hypothesis generation in chemical sensing studies.
